# Lower-Limb Exoskeleton – 5-DOF Kinematics

Kinematic model of a 5-degree-of-freedom robot for a rehabilitation exoskeleton of the lower limb, in MATLAB.

- Denavit–Hartenberg model and forward kinematics (`robot.m`, `cinematica_directa.m`)
- Inverse kinematics (`cinematica_inversa.m`, live script `ciematica_inversa_exoesqueleto.mlx`)
- Jacobian and singularity analysis (`jacobiano.m`)
- Workspace mapping (`workspace_robot.m`, `espacio_trabajo_OK.m`)
- Trajectory planning and generation for gait (`trayectorias.m`)

Requires MATLAB and Peter Corke's Robotics Toolbox.

Course project, Robotics, Universidad Nacional de Cuyo.
